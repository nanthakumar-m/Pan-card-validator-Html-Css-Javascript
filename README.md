# 🧾 PAN Card Validator – HTML | CSS | JavaScript

This PAN Card Validator is a web-based tool that checks whether a given PAN (Permanent Account Number) is valid based on the official Indian PAN format using regular expressions. It provides immediate feedback to users about the validity of the entered PAN.

The primary goal of this project was to understand and implement form validation, work with regular expressions (RegEx), and improve user input handling.

Click here to the live demo  --> https://nanthakumar-m.github.io/Pan-card-validator-Html-Css-Javascript/index2.html

## ⚙️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 💡Core Features

✅ Validates Indian PAN number format using RegEx: 5 letters + 4 digits + 1 letter

✅ Real-time feedback without page refresh

✅ Form submission prevention for better UX

✅ Simple, neat layout with CSS styling

✅ Color-coded result feedback (green for valid, red for invalid)


## 🎯 What I Gained  / Concepts Practiced

✅ Learned how to construct and apply regular expressions in JavaScript

✅ Understood client-side form validation logic

✅ Practiced DOM manipulation and event handling
